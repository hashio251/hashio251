## 🧩 Applications & Automation

### STATUS HOUSE CLI · Java

HTTPステータスコードを、訪問者ログの操作結果と結びつけて学ぶCLIアプリです。名前・部屋番号での検索に対応し、たとえばログの登録に成功すると `201 Created`、検索結果が存在しないと `404 Not Found` を表示します。

最初に登録・表示・編集・削除を実装しました。その後、メニュー・処理・データ管理を `ui`・`service`・`repository` に分け、ステータスコードは `HttpStatus` の `enum` にまとめました。

[コード・フローチャート](https://github.com/hashio251/05_javaApp_stats-house-experience) · [関連するWeb版のリポジトリ](https://github.com/hashio251/04_js_http-status-hall)

### Quist · Python / Django / SQLite

支出を記録してカテゴリごとに管理する家計管理アプリです。ログイン・ログアウト、支出とカテゴリの管理、支出や達成率を確認できるダッシュボードを実装しました。

Djangoのアプリを認証・支出・カテゴリ・ダッシュボードなどに分けています。金額の表示はテンプレートフィルターにまとめ、ロケールにかかわらず3桁ごとにカンマが入るようにしました。

[コード・セットアップ手順](https://github.com/hashio251/03_pythonapp_asset-management-app)

### Gmail Auto Labeling & Cleanup · Google Apps Script

業務用メールボックスで必要なメールと通知が混在していたことをきっかけに作りました。送信元やキーワードでスレッドを探してラベルを付ける処理を、検索条件やラベル名を差し替えて私用でも使えるようにしています。

整理対象の件名をログで確認する関数と、スレッドをゴミ箱へ移動する関数を用意しました。ラベル付けや移動は100スレッドずつ処理します。

[コード・設定例](https://github.com/hashio251/06_GAS/tree/main/01_gmail/labeling)
